# 담이 산책 일기 v3 — 마을 산책 생활 게임

아기 말티푸 담이와 마을에서 사는 힐링 게임. 모든 그림·소리는 코드로 생성, 폰트는 Galmuri(OFL).

## 실행
- PC: `index.html` 열기
- 휴대폰: 가로 화면. GitHub Pages에 이 폴더를 그대로 올리면 링크로 플레이 가능 (빌드 필요 없음)
- 예전 버전: `v1_백업.html`(8비트), `v2_백업.html`(2.5D 첫 버전)

## 조작
| | PC | 휴대폰 |
|---|---|---|
| 이동 | 방향키/WASD | 화면 왼쪽 드래그(조이스틱) |
| 행동(대화·문·담이·물건) | E / Enter | [행동] |
| 담이 부르기 | 스페이스 | [부르기] |
| 할 일 / 지도 / 도감 / 메뉴 | T / M / F / Esc | 위쪽 버튼 |

## 하루 흐름
1. 아침(집): 밥그릇·물그릇 채우기
2. 낮(마을·산책): 주민 집에 들어가 부탁(퀘스트) 받기 → 마을 오른쪽 출구 → 산책 지도에서 장소 고르기
3. 저녁(집): 저녁밥 → 간식 타임(담이 메뉴) → 샤워 타임(욕조: 거품→헹굼→말리기) → 침대에서 잠자기 → 일기

## 성장 요소
- 🦴 코인: 퀘스트·산책 완주·보물 → 펫샵(사료·간식·리본·꽃핀·반다나·밀짚모자·별 머리핀)
- 산책 레벨: 장소 열림 (공원·골목길 → Lv2 뒷산 → Lv3 강변)
- 우정 레벨: 재주 열림 (앉아 → 손 → 엎드려 → 빵야!), 재주는 할수록 성공률 상승
- 친구 강아지 도감 6마리, 보물 상자 8종 (담이가 킁킁 땅 파서 찾음)
- 장기 목표: DAY 10 마을 강아지 축제 장기자랑 (재주·친구·꾸미기·우정으로 점수)

## 파일 구조
- `js/lib.js` 공용(난수·소리·지형·나무) / `js/data.js` 장소·주민·퀘스트·상점 / `js/art.js` 캐릭터·가구 그림
- `js/world.js` 저장·하루 일정·지역 생성 / `js/game.js` 진행·담이 행동·퀘스트 / `js/ui.js` 화면·입력·메뉴
- `js/net.js` 2인 멀티플레이 자리 (현재 꺼짐)

## 멀티플레이 준비 (GitHub + Supabase, 예정)
- 저장 데이터 `SV`가 JSON 하나라서 Supabase 테이블(jsonb)에 그대로 저장 가능
- 위치 공유는 Supabase Realtime 채널로 계획 (`js/net.js` 주석 참고)
- 넣을 값은 Supabase **URL과 anon(공개) 키뿐**. 서비스 키·비밀번호는 코드에 넣지 않음. 테이블 보호는 RLS 정책으로
